# AgriNova

AgriNova is a marketing and demo site for an AI-powered agritech platform focused on crop intelligence, early stress detection, and climate-smart agriculture.

## Features

- Premium agritech landing pages for AgriNova
- Route-based navigation across marketing pages
- Browser-only image upload demo with sample analysis output
- Responsive UI with modern SaaS styling and shared design tokens

## Local development

Requirements:
- Node.js
- npm

Commands:

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Project structure

- src/routes: route-based pages
- src/components/agrinova: shared marketing and shell components
- src/lib: app logic and demo data
- src/styles.css: shared visual tokens and site styling
